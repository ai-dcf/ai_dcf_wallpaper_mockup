# 1:1 完美克隆计划 (静态镜像与域名锁破解)

## 1. 目标摘要 (Summary)
用户之前选择了“源码重构”方案，但发现视觉和细节无法达到 1:1 完美还原。经过沟通，现改用“**原站静态镜像 + 域名锁破解**”方案，以保证 100% 完美的 1:1 视觉和功能复刻。我们将直接使用已抓取下来的前端静态文件（HTML/JS/CSS），通过修改混淆的 JS 代码和劫持环境对象来绕过原站的域名检测。

## 2. 当前状态分析 (Current State Analysis)
- 原站的文件已通过 `wget` 抓取至 `/workspace/clone/mjcn.club/app/`。
- 其中核心 JS 文件 `app-300c4be7.js` (大约 3MB) 经过高度混淆，并包含环境检测逻辑。如果在非 `mjcn.club` 域名下运行，它会自动跳转（执行类似 `location.href = "https://mjcn.club"` 或报错）。
- 之前的重构项目位于 `/workspace/mockup-generator`，该项目由于是手工重写的，未能包含原站几百个样式和素材细节。

## 3. 提议的变更与实现步骤 (Proposed Changes)

### 阶段一：建立静态服务目录
- **文件迁移**：将抓取下来的 `mjcn.club/app/` 下的所有静态资源（HTML、CSS、JS、字体等）复制到一个全新的目录 `/workspace/static-clone` 中。

### 阶段二：破解前端域名锁定 (Domain Lock Crack)
- **字符串级替换**：编写 Node.js 脚本或使用 `sed` 命令，全量扫描核心混淆文件 `assets/app-300c4be7.js`。
- 将所有的 `mjcn.club` 替换为我们本地的调试域名（如 `localhost` 或当前环境的 IP/域名）。
- 将强制的 `https://` 检测替换为兼容 HTTP 协议。
- **BOM 环境劫持 (可选防线)**：在 `index.html` 的 `<head>` 最前面插入一段防御性脚本，劫持 `window.location` 的 `set` 方法，拦截任何试图重定向当前页面的行为，防止被混淆代码“踢出”页面。

### 阶段三：补全缺失资源与代理配置
- 原站可能存在部分绝对路径加载的资源（如图标、字体或接口），我们将检查这些请求，必要时配置一个简单的本地代理服务器（如使用 Vite 或 Express）进行转发，绕过跨域 (CORS) 限制。

### 阶段四：启动并验证
- 启动一个静态文件服务器（如 `python3 -m http.server` 或 `npx serve`）。
- 测试页面加载是否成功，是否能 1:1 展示所有数百种样机模板。
- 测试其上传、裁切和导出功能是否在破解后依然能正常工作。

## 4. 假设与决策 (Assumptions & Decisions)
- **废弃重构版**：我们决定彻底放弃之前手工重写的 Vue 3 代码，完全依赖原站的打包产物。
- **接口依赖**：原站纯前端生成样机的部分将 100% 可用；但如果原站存在需要与后端通信的高级功能（例如：获取最新模板列表 API、登录、高级会员校验等），破解版可能无法使用这些需要服务端配合的功能。我们重点保障本地样机的合成和导出功能。
